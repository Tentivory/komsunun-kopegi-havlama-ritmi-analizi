# Komşunun Köpeği Havlama Ritmi Analizi

## Özet (Ciddi)

Bu yazılım, insanlığın en acil sorunlarından biri olan "komşu köpek neden havlıyor ve ritmi nedir?" sorusuna bilimsel bir cevap verir. NASA, CERN ve TÜBİTAK bu projeyi gördükten sonra "biz bunu yapamayız, çok ileri" diyerek geri çekildi.

Gerçekten çalışır. Gerçekten saçmadır. İkisi de %100 doğru.

## Kullanım

```bash
python havlama_analizi.py
```

Program size rastgele havlama dizileri üretir, BPM hesaplar, derin felsefi yorumlar yapar ve gelecek havlamayı tahmin eder. Tahmin doğru çıkmazsa köpek suçludur, yazılım değil.

## Bilimsel Yöntem

1. Köpeği dinle (veya dinleme, kod zaten üretiyor).
2. Ritmi ölç (rastgele sayı üret).
3. Yorum yap (abartılı).
4. Tekrarla. Sonsuza kadar. Hayat gibi.

## Uyarı

Bu program çalıştırıldığında komşu köpek sizi dava edebilir. Sorumluluk kabul etmiyoruz. Ayrıca köpek "hav" demiyorsa belki kedi oluyordur, kontrol edin.

## Katkı

Pull request gönderin. "Hav hav" yazan herkes kabul edilir. Reddedilenler komşu köpeğe şikayet edilir.
